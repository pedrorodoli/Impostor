# Impostor Game 🕵️‍♂️
Juego multijugador inspirado en el popular juego del impostor, utilizando WebSockets para comunicación en tiempo real.

## 🚀 Tecnologías
- **Socket.io** (Comunicación en tiempo real)
- **Express** (Servidor web)
- **MySQL** (Persistencia de datos)
- **QRCode** (Para fácil acceso desde móviles)

## 🛠️ Instalación
1. Instala las dependencias: `npm install`.
2. Configura los datos de MySQL.
3. Ejecuta `npm start`.
